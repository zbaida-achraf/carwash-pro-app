# CarWash Pro — application Android (démo)

**Scan. Gagnez des points. Revenez.**

## Télécharger

👉 [**CarWashPro.apk**](https://github.com/zbaida-achraf/carwash-pro-app/releases/latest/download/CarWashPro.apk)

Installation : ouvrez le fichier sur votre téléphone Android → autorisez « Installer des applications inconnues » si demandé → Installer.
